# Master · 使用说明书

Master 是 T31-750 型仿人男性机器人控制系统（Male Android Control System）的控制台。本说明书覆盖随包发布的全部客户端：Android 与 Windows 上的 **Master** 控制台、随机器人携带的 **Slave** 应用、Wear OS 手表应用，以及浏览器版本和把各端连接起来的配对方式。

> 本产品为虚构设定。控制台中的许多读数——CPU/GPU/NPU 占用率、剩余仿真精液、剩余存储、系统版本、自检与更新过程输出——属于演出式呈现，并非真实遥测。下文对这类内容均标注为「模拟」。

# 0. 这套软件是干什么的

和自己的机器人**线下**见面，跟隔着屏幕聊天完全是两回事。凑在耳边下令可以，但话音一落就散了；用聊天软件发指令，一下把气氛打回原形——缺的是**仪式感**。

所以想象一下：你的机器人被彻底物化——所有参数可见、所有数值由你设定、实时掌握在你手里。一起出门时，它的手机与你的手机经蓝牙相连。在大街上，你不必贴近耳语，也不必在没有仪式感的聊天框里打字：你只在手机上点一点，它的手机随即亮起——**「主人指令」**——机器人像一台接收编程的机器一样，收到主人的最新指令。

回到家里，把控制台架到电脑前（或插上 U 盘直连），它就显出本来的样子：一台终端，面前站着动都不动、等着被你编程的机器。

这就是这套软件存在的意义：**有协议的物化**。一切，都在线下。接下来各章讲的是怎么把它用起来。

# 1. 客户端与分工

| 客户端 | 运行环境 | 应用名 | 作用 |
|---|---|---|---|
| 控制台（控制端） | Android 手机/平板（Android 12+） | **Master** | 完整控制台；对外广播蓝牙供各端连接 |
| 控制台（控制端） | Windows 10/11 桌面 | **Master** | 同一套控制台，外加桌面启动器与 USB 进入方式 |
| 接收端 | Android 手机（Android 7.0+） | **Slave** | 由机器人携带：显示模式、情绪、任务与语音消息，并可反向推送模式与语音指令 |
| 手表端 | Wear OS | 750接收端 | 腕上精简状态显示 |
| 浏览器版 | 任意现代浏览器 | — | 同一套控制台以网页形式提供，可选完整离线缓存 |

**控制端**负责分发状态，**接收端**与**手表端**负责接收展示。接收端还能把选定的模式回推给控制端，既可手动（长按模式胶囊），也可用语音。

**我该装哪一个？** 仅需控制时，装 Master 控制台即可；若要在另一部手机上查看机器人状态，再加装 Slave；手表端为可选项。

# 2. 安装与首次启动

## 2.1 一句话概括首次启动

所有客户端现在均**默认以英文打开**，能读到设备语言时自动匹配，并在进入主界面之前引导你完成一次初始设置。这些设置都不是必填项，每个首启界面都提供「跳过，保持默认」。

## 2.2 Android 版 Master

1. 安装 APK 并打开，先播放一次品牌宣传片。
2. 宣传片播完后出现**激活界面**（首次启动设置）。表单内容与 2.5 节相同，在手机上为单页滚动。
3. 按需填写个性化内容后点「开始使用」，或直接点「跳过，保持默认」。
4. 进入控制台。此后不会再出现该界面。

> 宣传片会完整播放后才出现首启界面；点按屏幕可提前结束播放。

## 2.3 Windows 版 Master

1. 将发布包解压到可写目录，运行 `RobotControl-Console.exe`。
2. **首次**启动时，激活窗口会在启动器**之前**弹出。完成设置，或直接关闭窗口跳过。
3. 进入启动器，等待机器人的 USB 设备接入（见 4.3 节）。
4. 点击设备按钮进入控制台。

此后启动不再弹激活窗口，直接进入启动器。若想重新体验首次启动流程：关闭应用，删除 `RobotControl-Console.exe` 同级的 `huancun` 文件夹，再启动即可。

## 2.4 Slave

1. 安装 APK 并打开。
2. 首启界面覆盖在主界面之上：选择「中文 / English」，可选填 MiMo API Key，并设置云端识别开关。
3. 点「开始使用」或「跳过，保持默认」。
4. 露出主界面，该界面不再出现。

## 2.5 激活表单

控制台的激活界面共十一组，一页完成。任何字段留空即保持默认。

版面随屏幕宽度自适应：手机上为整屏平铺（无卡片边框，顶部避开系统状态栏）；桌面宽屏下容器加宽、十组按两列排布，信息密度更高。**第 1 组「语言」本身就是语言入口**，页面右上角没有另外的切换按钮。每组标题以居中横幅分隔，一眼可辨。链接名称与状态项标签是**标题类输入框**（深底加粗，与值输入框区分）。

| # | 分组 | 字段 |
|---|---|---|
| 1 | **语言** | `中文` / `English` |
| 2 | **型号信息** | 完整型号、简称、制造公司、主人、语音播报读法 |
| 3 | **账号管理** | 登录密码与确认密码（两项均留空则保持 `admin` / `admin`） |
| 4 | **TTS 语音引擎** | 引擎 `白桦音色` / `音色设计`、MiMo API Key、MiMo 开放平台链接 |
| 5 | **机器人图片设置** | 两张图片文件与预览（建议 9:20 比例、带透明通道的图片） |
| 6 | **模式名称设置** | 重命名四大模式（每行附该模式的功能简介） |
| 7 | **信息面板链接** | 各链接条目的名称与地址 |
| 8 | **信息参数** | 第三条起的状态项标签与值 |
| 9 | **运行参数设置** | 剩余仿真精液、剩余电量、剩余存储 |
| 10 | **控制按钮文本设置** | 按钮文案；1–10 号固定不显示，仅 11 号及以后可编辑 |
| 11 | **通知推送（Clawbot）** | 状态行与「打开设置」按钮（弹出大窗配置 Telegram / 飞书推送，非必要项，可跳过） |

底部两个按钮吸底常驻结束流程：

- **开始使用** — 校验填写内容（两次密码一致、链接以 `http://` 或 `https://` 开头、精液当前量不大于总量、电量 0–100、存储量在范围内）并保存。
- **跳过，保持默认** — 除「已完成设置」这一标记外不写入任何内容。

此处或日后在设置页填写的型号信息会同步到窗口标题、顶栏、启动器标题、语音播报读法与状态胶囊。若整组都保持中文或英文默认值，则整组随界面语言切换；只要有一项被自定义，整组即按填写原样显示。

# 3. 语言

## 3.1 语言如何决定

各端按以下顺序确定界面语言：

1. **你手动选过的语言**（只要手动切过一次就永久记住）。
2. **设备语言** — 系统设为中文则以中文打开，否则以英文打开。
3. **英文**，当设备语言读不到或不是中文时。

自动检测每次启动都会重新判断，且**不写入存储**；因此因设备语言而显示中文的端，在你之后更改系统语言后仍会跟着变。只有手动切换才是永久的。

## 3.2 手动切换位置

| 客户端 | 切换位置 |
|---|---|
| Master 控制台 | 登录页右上角的 `ZH` / `EN`；激活页用第 1 组「语言」；进入控制台后为**设置 → 语言** |
| Master Windows 启动器 | 设置 → **界面语言** |
| Slave | 蓝牙对话框的**语言**行；或首启界面 |

切换即时生效并跨重启保留。Slave 上切换会重建界面，所有文案一次性更新。

## 3.3 Slave 不再跟随控制端

此前 Slave 会镜像控制端经蓝牙推送的语言。自本版本起 Slave 保持自己的语言：控制端的语言设置不再改变 Slave 的显示。请在 Slave 上自行设置。

> 蓝牙的语言特征仍然存在并照常广播，因此旧版 Slave 依旧可用——只是当前版本不再消费它。

# 4. 连接各端

各端通过低功耗蓝牙通信：控制端负责广播，接收端与手表端负责扫描并连接。

## 4.1 蓝牙扫描

1. 在控制台打开连接对话框，点「开始连接」。Windows 端同时会启动 BLE 宿主开始广播。
2. 在 Slave 上点圆形的 **B** 按钮打开「控制面板连接」，再点「重新扫描」，附近控制台会出现在列表中。
3. 点选设备即可连接。

Slave 每次扫描十秒，未绑定时会自动重试。连接成功后订阅模式、情绪、任务、语音、心跳与 API Key 通知（不再订阅控制台的语言，见 3.3）。链路断开时两端都会自动重连；由任一侧主动断开则会被尊重，不会陷入重连循环。

## 4.2 二维码配对

无需扫描列表即可完成配对：

1. 控制台蓝牙对话框中点二维码按钮，显示「绑定二维码」，提示用接收端扫描。
2. 在 Slave 上点「扫描二维码」。
3. 用摄像头对准二维码，Slave 读取到控制台地址后连接。

> 二维码生成需要原生壳（Android 或 Windows）。纯浏览器中没有蓝牙射频可读，二维码区域会保持空白。

## 4.3 Windows 的 USB 进入方式

Windows 启动器通过 USB 而非蓝牙识别机器人：

1. 打开启动器设置，至少添加一条规则。每条规则需填写 **VID**、**PID** 或**设备/磁盘 ID**；序列号与厂商名为可选细化条件。留空的字段不参与匹配。
2. 插入机器人。启动器每四秒扫描一次，报告状态，匹配成功时点亮设备按钮。
3. 点击设备按钮进入控制台。以此方式进入会被标记为 USB 进入，这正是保持连接期间显示「正在充电」的依据。

拔出设备会停止充电显示，重新插上则恢复。**测试模式**（`测试模式` 按钮或 F2 键）可模拟连接成功，便于在没有硬件时进入控制台；该状态仅在本次应用启动内有效。

## 4.4 从浏览器拉起 App

网页版提供 `robotcontrol://console` 协议，用于打开已安装的 Master 控制台。浏览器引导窗口与**设置 → 拉起 App** 均使用它。若未安装，浏览器会在约两秒后判定页面仍可见，转为高亮下载链接。

# 5. 控制台

控制台会自适应屏幕：宽屏桌面显示三栏，手机上显示单栏并通过页面切换。

## 5.1 登录

桌面端控制台在随机壁纸上显示登录卡片。

- **账号**、**密码** — 出厂账号为 `admin` / `admin`，除非你在激活时另行设置。
- **记住账号** — 保存凭据，下次自动填入。
- **进入控制台** — 播放一段过渡动画后加载主界面。

在手机宽度的窗口内以及 Android App 中**没有登录界面**：直接进入主界面，日志中会记录这一自动登录。

## 5.2 终端

终端在 `root:~#` 提示符下接受命令：

| 命令 | 作用 |
|---|---|
| `help` | 列出可用命令 |
| `mode` | 显示当前模式 |
| `mode test` / `recovery` / `loyalty` / `simulated-human` | 切换模式 |
| `system` | 打印规格表 |
| `clear` | 清屏 |
| `*` 加文本 | 语音播报该文本，并记为一条任务 |

上下方向键可翻阅历史命令。机器人关机期间输入会被禁用。

## 5.3 模式按钮

四个按钮用于选择运行模式，当前模式会高亮并呼吸。登录后初始为 **NA**（未设置模式）。

| 模式 | 特性 |
|---|---|
| 调试模式 | 无自我意识，仅响应指令 |
| 恢复模式 | 仅 BIOS 层运行，用于系统修复 |
| 忠诚模式 | 具备自我意识并服从，机器算法 |
| 拟人模式 | 行为如同人类，需要仿真皮肤 |

切换模式会播报模式名，并把新模式同步给所有已连接客户端。也可通过顶栏的模式菜单或终端的 `mode` 命令切换。

## 5.4 控制按钮

出厂共十二个按钮，可在设置中增添：

| 按钮 | 作用 |
|---|---|
| 清空所有进程 | 清空全部进程，带进度窗口 |
| 自检 | 运行自检程序 |
| 系统更新 | 运行更新流程 |
| 数据库更新 | 运行数据库迁移 |
| 开机 | 开机（仅在关机状态可用） |
| 关机 | 关机——停止语音播报、中止运行中的窗口、将各控件置灰 |
| 重启 | 重启：静默关机、等待、再开机 |
| 认知偏移 | 打开对话框，所填内容会作为认知任务加入并播报 |
| 暂停 | 暂停，图表保持平直；标签变为「结束暂停」 |
| 停止 | 停止并将唤起值图表归零；标签变为「恢复」 |
| 洗澡子模式 | 仅播报并记录日志 |
| 家具模式 | 仅播报并记录日志 |

11 号及以后的按钮由你自行定义，按下时也会记录一条任务。拟人模式下功能按钮全部禁用；关机期间仅「开机」与「重启」可用。

## 5.5 情绪面板

四个滑杆，可在轨道上任意位置点按或拖动，取值 0–100：

| 滑杆 | 颜色 | 默认值 |
|---|---|---|
| 服从度 | 绿色 | 100 |
| 羞耻度 | 橙色 | 0 |
| 愉悦度 | 粉色 | 100 |
| 机械度 | 红色 | 50 |

每次调整都会播报数值，并推送给已连接的客户端。数值跨会话保留。

## 5.6 状态参数

下方各面板列出机器人的各项参数——系列、代数、序列号、系统与数据库版本、机体与部件编号、身高、体重、尺寸、性别、取向、阈值、唤起条件、生产与激活日期。其中**主人**与**制造公司**两项跟随你设置的型号信息，其余各项在设置页逐条编辑。

## 5.7 运行参数与图表

监控面板显示剩余电量、剩余仿真精液、剩余存储，以及内存/CPU/NPU/GPU/读写占用率，并配有内温、系统负载与唤起值三条折线图。电量、精液与存储按你在设置中填写的数值显示；占用率与图表则按演出式呈现自行波动（模拟）。

关机后除电量外的项目全部显示 N/A，电量仍按既定计划继续走。

## 5.8 灵动岛、通知与代码视图

Android 与 Windows 端在有客户端连入或正在充电时会播放灵动岛动画。桌面窗口还会在右上角显示 macOS 风格通知，用于连接、断开、充电状态变化与模式推送成功等事件；最多同时堆叠三条，五秒后淡出。

第三个面板持续滚动显示机器人的源码，滚动速度随模拟 CPU 占用上升；另有一对图片展示机器人的两张参考照片，均可在设置中配置。

## 5.9 自检

点「自检」打开进度窗口，逐项走过诊断清单——型号、面部、机体、底盘、性功能配置与软件子系统——并报告已用时间与行数。桌面宽度下会在性功能测试环节出现文件传输窗口。成功结束时报出总用时并播报结果。运行中关闭窗口会先请求确认。

---

## 5.10 任务指令系统

任务面板列出机器人的任务，每条左侧标记来源：认知（橙色 ◈）、终端（青色 ◇）、按钮（模式色 ◆）、普通（●），已完成的划去并显示 ✓。面板标题右侧显示计数，例如「3 项任务（1 待完成）」。

本机产生的任务（如按下 11 号及以后的按钮、终端里用 `*` 下发指令、添加认知偏移）会即时进入该列表，并同步给已连接的 Slave 与手表端。

## 5.11 计时器

计时器面板提供「开始」与「重置」两个按钮，用于倒计时；倒计时结束会播报提示。时长与倒计时状态在会话内保留。

## 5.12 调试日志

调试日志面板按时间顺序记录系统动作：初始化、登录、连接、模式切换、功能执行、文件打开、设置保存等。排查问题时先看这里——多数「点了没反应」的情况在日志里都有对应记录。

## 5.13 顶栏与系统菜单

桌面菜单模式下，顶栏包含：

| 元素 | 作用 |
|---|---|
| 电池指示 | 打开电池菜单（充电状态与计划说明） |
| 网络指示 | 打开网络/蓝牙服务菜单 |
| 机器人模式指示 | 打开模式菜单，直接切换四大模式 |
| 蓝牙按钮 | 打开连接对话框（开始连接 / 二维码 / 断开） |
| **?** | 信息面板 |
| 齿轮 | 设置面板 |

点左上角 Rt5 标志打开系统菜单，含 **关于本机**、**重新启动机器人…**、**关闭机器人…**、**退出登录** 四项；「关于本机」窗口显示型号、公司、状态清单与 CPU/GPU/NPU 图表。程序坞（鼠标触底缘浮出）提供窗口管理与最小化入口，其浮窗区常驻 **App 使用说明书** 图标（书本造型），点击即在应用内打开本说明书。

## 6.1 配置文件

**导出配置** 生成 `robotcontrol-config-YYYYMMDD.json`，包含按钮文本、状态项、模式名称、型号信息、链接、运行参数、账号、两张图片、情绪值、语言、TTS 引擎与 MiMo API Key。

## 6.2 IM 通知推送（Clawbot）

把控制台里发生的事实时推送到 Telegram / 飞书聊天（群里的 Clawbot 或任何 bot 都能收到），也能在聊天里用斜杠指令反查机器人参数。**全部收发为纯 API 直连、本地解析回复，不经过任何大模型，0 token 消耗。** 如果无法安装 Slave 端（例如 iOS 设备无法侧载），可以使用该方法将命令推送到 IM 软件，作为命令下发的替代渠道。

接入教程：[飞书官方 · 自定义机器人](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot) · [飞书官方 · 机器人概览](https://open.feishu.cn/document/client-docs/bot-v3/bot-overview) · [Telegram 教程（中文）](https://github.com/danshui-git/shuoming/blob/master/bot.md) · [Telegram Tutorial (English)](https://core.telegram.org/bots/tutorial)。

**推送格式（两类分开）**

| 类别 | 触发时机 | 格式 |
|---|---|---|
| 指令播报 | 语音播报的内容（终端指令、控制按钮、模式切换、任务完成、系统通知等） | `主人指令：` + 实际内容 |
| 数据变更 | 实时修改的数据（情绪滑杆、任务增删、设置保存后的实际改动项、充电状态切换） | `数据变更：` + 变更内容 |

英文界面下前缀与内容自动翻成英文（`Master's Command: ` / `Data Change: `），模式名等文案取实际设置值。空白内容不推送。运行参数本身不推送（与不推给 Slave 端同口径），仅**充电状态切换**（开始/停止充电）推送一条。每个平台首次向会话发送时会先发一条绑定提示（完整型号 + 已被主人成功绑定……按界面语言，含英文版）。

**在哪里设置**：设置页「Clawbot 通知推送」组；首次激活第 11 节点「打开设置」会弹出大窗配置（非必要项，跳过不影响激活）。两处是同一套表单，含三个开关：推送语音播报内容 / 推送实时数据修改 / 响应斜杠指令查询。

**Telegram 接入**

1. 在 Telegram 找 `@BotFather`，`/newbot` 创建机器人，拿到 **Bot Token**（形如 `123456789:AA...`）。
2. 在 Telegram 里给该机器人**发送一条消息（如 `/start`）**，然后在设置表单点 **「自动获取会话 ID」**——自动填入你与机器人的会话 ID。也可以手填数字会话 ID（群为 `-100...` 开头、私聊为正整数），或粘贴 `@用户名` / `t.me` 链接（由系统自动解析）。**不能填机器人自己的用户名**（机器人无法作为会话接收消息）。
3. 勾选「启用 Telegram」，点「发送测试消息」验证。

需设备网络可达 `api.telegram.org`（大陆网络通常需系统代理）；反向查询用 getUpdates 长轮询，无需公网 IP。

**飞书接入（二选一）**

- **自定义机器人 Webhook（仅推送）**：群设置 → 群机器人 → 添加机器人 → 自定义机器人，复制 **Webhook URL** 填入。此模式不能接收斜杠指令，且**只能发到群**（不能与机器人单聊）。
- **自建应用（双向）**：飞书开放平台创建企业自建应用 → 开启机器人能力 → 申请 `im:message` 权限 → 发布版本 → 把机器人拉进目标群；填入 **App ID / App Secret / Chat ID**。

飞书大陆直连、无需代理；两平台可同时启用（消息双发，查询回复发回指令所在平台）。**单聊支持**：Telegram 支持与 bot 单聊；飞书自建应用可单聊——Chat ID 填个人 open_id（`ou_` 开头，仅推送）或单聊会话 ID（`oc_` 开头，支持斜杠查询）。

**斜杠指令（本地解析、0 token）**

| 指令 | 作用 |
|---|---|
| `/help` | 指令列表 |
| `/query` | 全部参数摘要 |
| `/mode` | 当前模式与模式名称 |
| `/emotion` | 情绪参数 |
| `/runtime` | 运行参数 |
| `/tasks` | 任务列表 |
| `/model` | 型号信息 |
| `/status` | 信息参数 |
| `/buttons` | 控制按钮文本 |
| `/links` | 信息面板链接 |

空白指令（空消息或单独 `/`）不支持、直接忽略；未知指令回帮助提示。回复语言跟随控制台语言设置，模式名等文案取实际设置值；账号密码与 API Key 只回「已设置/未设置」，Bot Token / App Secret 永不回显。推送队列限速每秒 1 条，超出自动排队。

> 控制台需保持运行（页面开着）才会响应查询；配置随「导出配置」带出，文件含 Bot Token 等敏感信息，勿外传。

# 8. Slave 应用

Slave 是随机器人携带的客户端。

## 8.1 界面布局

固定顶部区域放置蓝牙按钮、模式胶囊与语音识别按钮，其下为情绪面板。再往下是两列滚动区：左侧任务，右侧语音消息。

**模式胶囊**按各自颜色显示当前模式，无模式时为灰色 **NA**。**长按**可打开模式菜单，把另一模式推送给控制台；若未连接会给出提示。这是语音指令的手动等价操作。

## 8.2 蓝牙按钮

- **单击** 打开连接对话框。
- **长按** 注入模拟数据——一批演示任务、情绪与语音消息。这是测试辅助，并非真实数据。

按钮颜色：已连接为绿色、断开为红色、连接中为琥珀色、尚未配对为灰色。

## 8.3 连接对话框

「控制面板连接」内含连接状态与地址、附近设备列表与扫描控制、二维码入口，以及机器人自身需要的设置：

- **MiMo API Key** —— 可选；用于高质量语音合成。连接控制台时按双端同步策略自动对齐（见 8.7）。
- **识别引擎调用云端（MiMo ASR）** —— 开启时识别可回退到云端；关闭时仅用本机引擎，不向外发送任何内容。
- **语言** —— `中文` / `English`。
- **断开** —— 断开链路并清除配对。

## 8.4 语音识别

右上角圆形麦克风按钮用于开关识别。仅在应用处于前台时运行，并记住上次的开关状态。

识别优先在本机完成，按读音匹配模式名，因此近音词也能命中；以否定词（如「不」）开头的语句会被排除。识别同时遵循界面语言：中文界面识别中文模式名，英文界面识别英文。云端识别仅作为兜底，且必须同时满足开关开启、已有 Key、已采集到足够语音等条件。

识别到的模式会以与长按完全相同的链路推送给控制台。

## 8.5 任务与语音消息

**任务**按来源标注——认知、终端、按钮或普通，已完成的会划去。**语音消息**按时间倒序显示时间与内容；每条新消息都会发出系统通知，标题为「主人指令」，若该消息是控制台对你所推送模式的确认，则标题为「推送成功」。

## 8.6 隐私控制

未经你的许可不会有任何内容离开设备：云端识别由开关控制，API Key 仅用于 MiMo 服务。

## 8.7 API Key 双端同步

连接控制台后，双端的 MiMo API Key 自动对齐一次（以 Slave 端为裁决方）。判定「可用」看两点：格式合法（`sk-` 前缀且长度足够）且没有鉴权失败记录——真实 TTS/ASR 调用的成败会自动更新这一记录。

| Slave 端 | 控制台端 | 结果 |
|---|---|---|
| 空 / 失效 | 可用 | 采用控制台的 Key |
| 可用 | 空 / 失效 | 推送给控制台 |
| 都可用且相同 | — | 无需同步 |
| 都可用但不同 | — | 各用各的，不同步 |
| 都为空或失效 | — | 不变（不会清空任何一侧） |

换言之：**一侧为空或失效、另一侧有效时以有效方为准；双方有效且不一致时互不覆盖**。同一 Key 不会重复同步。

手表有三页，可左右滑动或用表冠滚动切换：

1. **情绪页** —— 与控制台相同的四个滑杆。
2. **任务页** —— 任务列表一览。

# 10. 浏览器版本

同一套控制台也能在浏览器中运行，与原生端主要有两点不同。

**首次访问是强制缓存流程。** 网页端首访会弹出「获取完整体验」窗口，且该窗口**不可关闭、不可忽略**——必须先点「缓存网页」把全部资源下载一次（窗口会自动重新弹回，防止绕过），完成后才进入控制台；此后控制台从本地运行、支持离线。缓存通过浏览器缓存存储（Cache Storage）实现，故需以 `http://`/`https://` 打开并允许站点存储数据。站点更新后会通过通知或横幅提示重新缓存。

缓存完成后，界面上仍会出现激活页（浏览器端同样有首次激活设置），以及 App 拉起引导。

**App 拉起。** 浏览器无法使用蓝牙；要连接硬件需使用 Android 或 Windows 应用。引导窗口提供「打开 App」「下载 App」「缓存网页」以及「不再提示」复选框；未安装应用时，点「打开 App」约两秒后会提示转为下载。

**设置 → 网页缓存与 App** 分组可随时重复缓存、拉起与下载操作。

# 11. 故障排查

| 现象 | 检查项 |
|---|---|
| 界面语言不对 | 更改系统语言，或手动切换——手动切换是永久的，会覆盖自动检测 |
| Slave 与控制台语言不同 | 这是预期行为：Slave 现在保持自己的语言。请在 Slave 上设置 |
| Slave 找不到控制台 | 确认控制台正在广播（打开其连接对话框并开始连接）、两台设备相距几米内，并让扫描走完十秒 |
| 二维码扫不出来 | 只有原生壳能生成可用二维码；浏览器中二维码区域为空，请改用扫描连接 |
| Windows 启动器一直等待 | 至少添加一条 USB 规则，或按 F2 进入测试模式 |
| 语音识别没有反应 | 检查麦克风权限、保持应用在前台，并确认界面语言与你说话的语言一致 |
| 手表自行断开 | 从蓝牙对话框打开保活指引，把应用加入电池优化白名单 |
| 设置改动没有生效 | 设置在你点「应用更改」时才写入，而非边输入边保存 |
| 控制台又出现首启界面 | 只有从未完成过初始设置才会再次出现；完成或跳过即可 |
